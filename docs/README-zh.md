# wihxlyy.github.io

这是 `wihxlyy` 的个人主页，使用 Jekyll 和 AcadHomepage 模板搭建。

## 修改主页

- `_config.yml`：修改主页标题、简介、头像和社交链接。
- `_pages/about.md`：控制主页各个部分的显示顺序。
- `_pages/includes/`：存放 About、News、Projects 等部分的正文。
- `images/profile.png`：侧边栏头像。

## 本地运行

安装 Ruby 和 Bundler 后，在仓库根目录运行：

```bash
bundle install
bundle exec jekyll serve
```

然后打开 <http://127.0.0.1:4000>。

主页地址为 <https://wihxlyy.github.io>。
