# wihxlyy.github.io

Personal homepage for `wihxlyy`, built with Jekyll and the AcadHomepage template.

## Edit the homepage

- `_config.yml` contains the site title, description, avatar, and social links.
- `_pages/about.md` controls the page order.
- `_pages/includes/` contains the text for each homepage section.
- `images/profile.png` is the profile image shown in the sidebar.

## Run locally

Install Ruby and Bundler, then run:

```bash
bundle install
bundle exec jekyll serve
```

Open `http://127.0.0.1:4000` in a browser.

The site is published by GitHub Pages at `https://wihxlyy.github.io`.
